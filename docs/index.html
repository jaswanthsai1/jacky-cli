JACKY

The AI CLI built for hunting — bug bounty, pentesting, and full-stack coding automation. Local or cloud. Yours to run anywhere.

Get Started View on GitHub 
$ git clone https://github.com/jaswanthsai1/jacky-cli.git
$ cd jacky-cli
$ ./setup.sh
# ...installs, links `jacky` onto PATH, verifies `jacky --help`...
$ jacky
status: ONLINE

What makes it different

Local or cloud, your choice

Run fully offline against Ollama/llama.cpp and any tool-calling-capable model, or point it at any OpenAI-compatible / Anthropic-compatible cloud provider with your own API key. Switch any time, no code changes.

Bundled hunt-loop methodology

Ships with a real offensive-security doctrine: scope → recon → rank → enumerate → test → validate → chain → report, plus per-vulnerability-class playbooks and a finding-validation gate.

Self-improving skill system

The agent writes and refines reusable skills as it works, building procedural memory instead of starting from zero every session.

Full tool-calling agent loop

A real terminal interface, MCP client for any external tool server, persistent memory, and context compression that scales to large context windows.

The hunt loop

scope→ recon→ rank→ enumerate→ test→ validate→ chain→ report

Class playbooks cover SSRF, IDOR, XSS, SQLi, SSTI, auth bypass, business logic, race conditions, CORS, subdomain takeover, JWT/OAuth, API misconfiguration, cloud/K8s misconfiguration, and more.
