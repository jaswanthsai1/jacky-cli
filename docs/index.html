The AI CLI built for hunting and building

Jacky CLI is a self-improving agent CLI: a real tool-calling loop, a bundled offensive-security hunt methodology, and a skill system that writes and refines its own procedures as it works — running fully offline against local models or against any cloud provider you bring a key for.

Capabilities

      
What Jacky actually does

      
No fluff — five things it ships with today.

    

    

      

        
⇄

        
Dual local + cloud models

        
Run fully offline against Ollama and any tool-calling-capable GGUF model — zero API cost, nothing leaves your machine — or point it at any OpenAI-compatible or Anthropic-compatible cloud provider with your own key. Switch with jacky model, no code changes.

      

      

        
🎯

        
Bundled bug-hunt methodology

        
Ships with a real offensive-security doctrine under skills/: scope → recon → rank → enumerate → test → validate → chain → report, plus finding-validation gates and evidence-hygiene discipline.

      

      

        
🛠

        
Tool-calling agent loop

        
40+ built-in tools, an MCP client for connecting any MCP server, a toolset system for scoping what's available per session, and a full terminal interface with streaming tool output.

      

      

        
🧠

        
Self-improving skill system

        
Agent-curated memory with periodic nudges. Autonomous skill creation after complex tasks — skills refine themselves during use. Compatible with the open agentskills.io standard.

      

      

        
⌁

        
One-command install

        
Clone the repo, run ./setup.sh, and it creates the virtualenv, installs Jacky, links the jacky command onto your PATH — then actually runs jacky --help to prove the install works before declaring success.

Get running

      
Quick Start

      
The real commands from the README — no build step required.

    

    

      

        

          bash
          
        

        
$ git clone https://github.com/jaswanthsai1/jacky-cli.git
$ cd jacky-cli
$ ./setup.sh
# creates the venv, installs Jacky, links `jacky` onto PATH,
# then runs `jacky --help` to prove the install works
$ jacky

      

      

        
What setup.sh does

        
It finds a usable Python 3.11–3.13 interpreter, creates a virtual
        environment, installs Jacky CLI (editable) into it, copies
        .env.example → .env,
        and symlinks the jacky command onto your PATH —
        before declaring success it actually runs jacky --help
        to prove the install works.

        
    
          
  • Linux, macOS, or Windows (native via scripts/install.ps1, or WSL)

  • Optional: Ollama for fully local models
