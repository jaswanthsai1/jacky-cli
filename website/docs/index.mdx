## Quick Start {#quick-start}

Every real install path — pick whichever fits your platform. All of them end
with the `jacky` command on your `PATH`.

<Tabs groupId="install-method">
<TabItem value="oneline" label="One-line (GitHub)" default>

```bash
curl -fsSL https://raw.githubusercontent.com/jaswanthsai1/jacky-cli/main/install.sh | bash
```

Clones the repo to `~/.jacky-cli`, runs `setup.sh` for you, and leaves
`jacky` on your `PATH`. Re-running it later updates your install in place.

</TabItem>
<TabItem value="manual" label="Manual (git clone)">

```bash
git clone https://github.com/jaswanthsai1/jacky-cli.git
cd jacky-cli
./setup.sh
jacky
```

`setup.sh` creates a virtual environment, installs Jacky CLI into it, copies
`.env.example` → `.env`, links the `jacky` command onto your `PATH`, and —
before declaring success — actually runs `jacky --help` to prove the install
works.

</TabItem>
<TabItem value="npm" label="npm">

```bash
npm install -g jacky-cli-agent
```

Live on npm today. Jacky checks for updates on startup and tells you when
`npm update -g jacky-cli-agent` is worth running.

</TabItem>
<TabItem value="pypi" label="pip (PyPI)">

```bash
pip install jacky-cli
```

Live on PyPI today — installs the `jacky` command via `pip`/`pipx` on any OS
with Python 3.11–3.13.

</TabItem>
<TabItem value="pip-git" label="pip (via git)">

```bash
pip install git+https://github.com/jaswanthsai1/jacky-cli.git
```

Installs straight from the repository, no PyPI release required — useful for
tracking `main`.

</TabItem>
<TabItem value="windows" label="Windows (native)">

```powershell
git clone https://github.com/jaswanthsai1/jacky-cli.git
cd jacky-cli
powershell -ExecutionPolicy ByPass -File scripts\install.ps1
```

See the [Windows Native guide](/user-guide/windows-native) for the feature
matrix, or [Windows + WSL Quickstart](/user-guide/windows-wsl-quickstart) if
you'd rather run it under WSL2.

</TabItem>
</Tabs>

See the full **[Installation Guide](/getting-started/installation)** for what
the installer does, the per-user vs root layout, and platform-specific notes.
For the complete platform support matrix, see
**[Platform Support](/getting-started/platform-support)**.

:::tip Fastest path to a working agent
After installing, run `jacky setup --portal` — one OAuth covers a model plus
all four Tool Gateway tools (web search, image generation, TTS, browser). See
[Nous Portal](/integrations/nous-portal).
:::

## What is Jacky CLI?

It's not a coding copilot tethered to an IDE or a chatbot wrapper around a
single API. It's an **autonomous agent** that gets more capable the longer it
runs, and it ships with a real offensive-security hunt-loop methodology out
of the box — not bolted on. It lives wherever you put it — a $5 VPS, a GPU
cluster, or serverless infrastructure (Daytona, Modal) that costs nearly
nothing when idle. Talk to it from Telegram while it works on a cloud VM you
never SSH into yourself. It's not tied to your laptop.

## Key Features

- **A closed learning loop** — Agent-curated memory with periodic nudges, autonomous skill creation, skill self-improvement during use, FTS5 cross-session recall with LLM summarization, and [Honcho](https://github.com/plastic-labs/honcho) dialectic user modeling
- **A bundled bug-hunt methodology** — a real offensive-security doctrine (scope → recon → rank → enumerate → test → validate → chain → report) with class playbooks for SSRF, IDOR, XSS, SQLi, SSTI, auth bypass, business logic, race conditions, and more. See [Methodology](/methodology/).
- **Built-in security toolset** — raw HTTP client for API testing, secret scanner, SCA dependency audit against OSV.dev, CVSS v3.1 + Bugcrowd VRT severity calculator, semgrep-backed static analysis (SQLi/command-injection/SSRF/deserialization patterns), passive CT-log/DNS recon, and structured evidence-bundle reports — all on by default. See [Tools Reference](/reference/tools-reference#security--recon-toolsets).
- **Runs anywhere, not just your laptop** — 6 terminal backends: local, Docker, SSH, Daytona, Singularity, Modal. Daytona and Modal offer serverless persistence — your environment hibernates when idle, costing nearly nothing
- **Lives where you do** — CLI, Telegram, Discord, Slack, WhatsApp, Signal, Matrix, Mattermost, Email, SMS, DingTalk, Feishu, WeCom, Weixin, QQ Bot, Yuanbao, BlueBubbles, Home Assistant, Microsoft Teams, Google Chat, and more — 20+ platforms from one gateway
- **Scheduled automations** — Built-in cron with delivery to any platform
- **Delegates & parallelizes** — Spawn isolated subagents for parallel workstreams. Programmatic Tool Calling via `execute_code` collapses multi-step pipelines into single inference calls
- **Open standard skills** — Compatible with [agentskills.io](https://agentskills.io). Skills are portable, shareable, and community-contributed via the Skills Hub
- **Full web control** — Search, extract, browse, vision, image generation, TTS — one subscription via [Nous Portal](/integrations/nous-portal) bundles all of them
- **MCP support** — Connect to any MCP server for extended tool capabilities
- **Research-ready** — Batch processing, trajectory export, RL training with Atropos
